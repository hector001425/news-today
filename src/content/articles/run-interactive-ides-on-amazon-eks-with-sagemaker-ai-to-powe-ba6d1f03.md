Amazon Web Services (AWS) anunció la posibilidad de ejecutar entornos de desarrollo integrados (IDEs) interactivos sobre Amazon Elastic Kubernetes Service (EKS) en combinación con SageMaker AI, su plataforma central para el desarrollo de modelos de inteligencia artificial.

La integración permite a los equipos de datos y machine learning trabajar directamente desde IDEs familiares —como JupyterLab o Code Server— sobre infraestructura orquestada con Kubernetes, sin necesidad de abandonar sus flujos de trabajo habituales ni gestionar servidores de forma manual.

Con esta capacidad, AWS busca reducir la fricción entre el desarrollo experimental y el despliegue productivo de modelos, permitiendo que los científicos de datos aprovechen la escalabilidad y flexibilidad de EKS mientras mantienen la experiencia interactiva propia de un entorno de notebooks.

El anuncio se enmarca en la estrategia de AWS por consolidar SageMaker AI como una plataforma unificada para todo el ciclo de vida del desarrollo de IA, desde la experimentación hasta la inferencia en producción.
